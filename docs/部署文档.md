# 商户记账系统 - 部署文档

## 环境要求

- **服务器**: 1核2G起步（推荐2核4G）
- **系统**: Ubuntu 20.04+ / CentOS 7+
- **数据库**: PostgreSQL 14+
- **Docker**: 20.10+ (可选，推荐使用)

---

## 方式一：Docker 部署（推荐）

### 1. 安装 Docker

```bash
# Ubuntu
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER

# 启动 Docker
sudo systemctl enable docker
sudo systemctl start docker
```

### 2. 安装 PostgreSQL

```bash
# 使用 Docker 运行 PostgreSQL
docker run -d \
  --name merchant-postgres \
  -e POSTGRES_DB=merchant_accounting \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=your_password \
  -p 5432:5432 \
  -v postgres_data:/var/lib/postgresql/data \
  postgres:14
```

### 3. 部署后端服务

```bash
# 拉取镜像（或使用本地构建）
docker run -d \
  --name merchant-api \
  -p 8080:8080 \
  -e DB_HOST=你的数据库IP \
  -e DB_PORT=5432 \
  -e DB_USER=postgres \
  -e DB_PASSWORD=your_password \
  -e DB_NAME=merchant_accounting \
  -e API_PORT=8080 \
  -e QWEN_API_KEY=你的通义千问Key \
  -e QWEN_VL_API_KEY=你的通义千问VLKey \
  -e TENCENT_ASR_SECRET_ID=你的腾讯云SecretId \
  -e TENCENT_ASR_SECRET_KEY=你的腾讯云SecretKey \
  --restart unless-stopped \
  merchant-llm-accounting:latest
```

### 4. 验证服务

```bash
curl http://localhost:8080/health
# 返回 {"status": "ok"} 表示成功
```

## 方式二：直接部署

### 1. 安装 Go

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install -y golang-go

# 验证
go version
```

### 2. 安装 PostgreSQL

```bash
# Ubuntu
sudo apt install -y postgresql postgresql-contrib

# 启动
sudo systemctl start postgresql
sudo systemctl enable postgresql

# 创建数据库
sudo -u postgres psql
CREATE DATABASE merchant_accounting;
\q
```

### 3. 部署后端

```bash
# 克隆代码
git clone https://github.com/victoryann-claw/merchant-llm-accounting.git
cd merchant-llm-accounting

# 安装依赖
go mod download

# 编译
go build -o merchant-api ./cmd/server

# 创建配置文件
cat > .env << EOF
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=your_password
DB_NAME=merchant_accounting
API_PORT=8080
QWEN_API_KEY=你的通义千问Key
QWEN_VL_API_KEY=你的通义千问VLKey
TENCENT_ASR_SECRET_ID=你的腾讯云SecretId
TENCENT_ASR_SECRET_KEY=你的腾讯云SecretKey
EOF

# 运行
./merchant-api
```

### 4. 配置系统服务（systemd）

```bash
sudo cat > /etc/systemd/system/merchant-api.service << EOF
[Unit]
Description=Merchant Accounting API
After=network.target postgresql.service

[Service]
Type=simple
User=www-data
WorkingDirectory=/opt/merchant-accounting
ExecStart=/opt/merchant-accounting/merchant-api
EnvironmentFile=/opt/merchant-accounting/.env
Restart=always

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable merchant-api
sudo systemctl start merchant-api
```

## 环境变量说明

| 变量 | 必填 | 说明 | 示例 |
|------|------|------|------|
| `DB_HOST` | 是 | 数据库地址 | localhost |
| `DB_PORT` | 是 | 数据库端口 | 5432 |
| `DB_USER` | 是 | 数据库用户 | postgres |
| `DB_PASSWORD` | 是 | 数据库密码 | xxx |
| `DB_NAME` | 是 | 数据库名 | merchant_accounting |
| `API_PORT` | 否 | API端口，默认8080 | 8080 |
| `QWEN_API_KEY` | 是 | 通义千问API Key | sk-xxx |
| `QWEN_VL_API_KEY` | 否 | 通义千问VL Key（图片识别用） | sk-xxx |
| `TENCENT_ASR_SECRET_ID` | 否 | 腾讯云SecretId（语音识别用） | xxx |
| `TENCENT_ASR_SECRET_KEY` | 否 | 腾讯云SecretKey（语音识别用） | xxx |

## Nginx 反向代理配置

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

启用 HTTPS（使用 Let's Encrypt）：

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d your-domain.com
```

## 小程序配置

### 1. 修改后端地址

在小程序 `app.js` 中修改：

```javascript
globalData: {
  baseUrl: 'https://你的域名/api/v1'  // 生产环境用https
}
```

### 2. 小程序后台配置

- 登录微信公众平台
- 开发管理 → 开发设置 → 服务器域名
- 添加 request 合法域名：`https://你的域名`

## 常见问题

### 1. 数据库连接失败
```bash
# 检查 PostgreSQL 是否运行
sudo systemctl status postgresql

# 检查端口是否通
telnet DB_HOST 5432
```

### 2. LLM 接口报错
```bash
# 检查 API Key 是否正确
# 确认网络能访问对应服务商

# 通义千问
curl -X POST https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen-turbo","messages":[{"role":"user","content":"hi"}]}'
```

### 3. 端口被占用
```bash
# 查看端口占用
lsof -i:8080
# 或
netstat -tlnp | grep 8080
```
