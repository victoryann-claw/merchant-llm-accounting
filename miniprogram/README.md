# 商户记账小程序

## 项目结构

```
miniprogram/
├── app.js              # 应用入口
├── app.json            # 应用配置
├── app.wxss            # 全局样式
├── api/
│   └── api.js          # API 接口封装
├── pages/
│   ├── index/          # 首页（今日看板）
│   ├── record/         # 录入页（语音/文字记账）
│   ├── records/        # 记录列表
│   └── report/         # 报表页
└── utils/
```

## 页面说明

### 首页 (pages/index)
- 今日收款/进货统计
- 快捷操作入口
- 最近3条记录预览

### 录入页 (pages/record)
- 按住说话录音
- 文字输入
- LLM 解析结果预览
- 确认提交

### 记录页 (pages/records)
- 按日期范围筛选
- 按类型筛选（进货/送货/付款）
- 自然语言查询
- 删除记录

### 报表页 (pages/report)
- 日/周/月报表切换
- 汇总统计
- 分类统计

## 运行

1. 在微信开发者工具中导入 `miniprogram` 目录
2. 修改 `app.js` 中的 `baseUrl` 为后端服务地址
3. 编译运行

## 注意事项

- 语音识别需要接入微信的语音识别 API
- 需要后端服务运行在可访问的地址
- 首次使用会自动创建商户
